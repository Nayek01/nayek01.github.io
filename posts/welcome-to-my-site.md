# Hello and welcome!

Thank you for stopping by my personal site. I built this website to create a home on the web where I can share my journey, document what I'm building, and post about software engineering, technology, and personal projects.

## What You'll Find Here

This site is divided into three main sections:

1. **[Curriculum Vitae (CV)](cv.html)**: A summary of my professional experience, education, key technical skills, and achievements. You can browse it online or download it as a PDF anytime.
2. **[Projects](projects.html)**: A showcase of things I've built, experiments, open-source contributions, and side projects.
3. **[Blog & Notes](posts.html)**: Articles and write-ups where I dive deeper into technical concepts, tutorials, architecture decisions, and lessons learned.

## Why Markdown for Posts?

Every post on this site is a clean Markdown file stored in the `posts/` directory. Markdown allows for:
- Writing without distractions.
- Effortless code blocks with syntax highlighting.
- Clean embedding of images, diagrams, and formatting.
- Version control with Git on GitHub.

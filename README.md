# Personal Website & Portfolio (GitHub Pages)

A modern, fast, responsive personal portfolio website hosted on **GitHub Pages**, designed with a high-contrast dark aesthetic, fluid responsive typography, and an automated Markdown blogging workflow:

- **Hero Profile Showcase**: Two-image developer profile card (wide cover banner + 50% overlapping circular avatar) with centered mobile stat pills.
- **Skills & Technologies**: Responsive 5-card-per-row grid featuring custom SVG technology logos.
- **Featured Projects**: High-impact production architecture showcase cards with live demo and GitHub repository links.
- **Latest Articles & Notes**: Alternating (zig-zag) editorial feed on the home page with custom vector cover illustrations.
- **Markdown Blog Engine**: Automatic catalog indexing (`build-posts.js`), live search, tag filtering (`posts.html`), and client-side Markdown reader (`post.html`).
- **Curriculum Vitae (CV)**: Interactive web view + PDF preview and direct download (`assets/cv.pdf`).
- **Interactive Contact Section**: "Wanna talk ?" contact form with instant validation and email draft triggering.

## 🔄 Dynamic vs. Manual: How Projects and Posts Are Updated

A common question is: **"Does the site automatically fetch the latest blogs and projects, or do I update them manually?"**

Here is exactly how both sections work:

### 1. Featured Projects (Home Page: `index.html`)
- **How it works**: **Static HTML (Manual)**.
- **Why**:
  - Delivers **zero-lag instantaneous page loads** without client-side API latency.
  - Guarantees **zero Cumulative Layout Shift (CLS)** for optimal Google PageSpeed scores.
  - Gives you **curated editorial control** to handpick your top 3 production-grade systems, custom metric pills (`⚡ 99.99% Uptime`), and specific repository links.
- **How to update or change projects**:
  Open `index.html` and locate `<section class="featured-projects-section" id="featured-projects">`. Edit any of the `.featured-project-card` blocks:
  ```html
  <div class="featured-project-card">
    <div>
      <div class="project-card-top">
        <span class="project-category-badge">Cloud & DevOps</span>
        <div class="project-card-links">
          <a href="https://github.com/YourUsername/repo" class="project-icon-link">...</a>
          <a href="https://your-live-demo.com" class="project-icon-link">...</a>
        </div>
      </div>
      <h3 class="project-card-title">My Project Name</h3>
      <p class="project-card-desc">Short 2-line summary of what this system does.</p>
      <div class="project-card-metrics">
        <span class="project-metric-pill">🚀 10k RPS</span>
      </div>
    </div>
    <div class="project-tech-tags">
      <span class="project-tech-tag">Docker</span>
      <span class="project-tech-tag">Node.js</span>
    </div>
  </div>
  ```

### 2. Blog Posts & Articles: Two Environments

The blog engine uses a **hybrid approach** to balance speed on the home page with automated cataloging on the blog page:

| Section / Page | Update Method | Description |
|---|---|---|
| **All Posts Catalog (`posts.html`)** | **100% Automatic** | Reads `posts/posts.json`. Adding a Markdown file and running `node build-posts.js` updates this page automatically with search and tag filters. |
| **Home Page Showcase (`index.html`)** | **Static HTML (Curated)** | Hardcoded preview cards in `index.html` featuring the alternating (zig-zag) cover image layout. Hand-picked for the home page. |
| **Single Post Reader (`post.html`)** | **100% Dynamic** | Parses `.md` files in real-time from the URL parameter (e.g., `post.html?post=my-file.md`). |

#### How to update the Home Page "Latest Articles & Notes":
When you publish a new article that you want featured on the home page:
1. Open `index.html` and locate `<section class="latest-posts-section" id="latest-posts">`.
2. Update the `.home-post-row` card:
   - **Cover Image**: Change `src="posts/images/your-cover.svg"`
   - **Title**: Update the text and `href="post.html?post=your-article.md"`
   - **Description**: Update the summary paragraph.
   - **Metadata**: Update the date, read time, and tags.
3. Keep the alternating pattern:
   - Card 1: Cover on Left, Text on Right.
   - Card 2: Text on Left, Cover on Right (`flex-direction: row-reverse` handled automatically).
   - Card 3: Cover on Left, Text on Right.

## ✍️ How to Publish a New Blog Post (Step-by-Step)

1. **Create the Markdown file**:
   Add a new `.md` file inside the `posts/` folder (e.g. `posts/cloud-scaling-guide.md`).

2. **Add YAML Frontmatter** at the top:
   ```markdown
   ---
   title: "Production Cloud Scaling: Architecture Guide"
   date: "2026-09-05"
   excerpt: "A deep dive into auto-scaling Kubernetes clusters and Redis pub/sub pipelines."
   author: "Ritwik Nayek"
   tags: [Cloud, Kubernetes, DevOps]
   coverImage: "posts/images/cloud-guide.svg"
   ---

   # Production Cloud Scaling: Architecture Guide
   Write your post here using standard Markdown...
   ```

3. **Add Cover or Embedded Media (Optional)**:
   Place images or SVGs into `posts/images/`.

4. **Rebuild the Post Index**:
   Run:
   ```bash
   node build-posts.js
   ```
   *Output*: `Successfully generated posts/posts.json with X posts!`
   This immediately updates the catalog on `posts.html` with your new post, tag filters, and search indexing.

## 📬 How the Contact Form Works ("Wanna talk ?")

The contact card on `index.html` provides a frictionless way for visitors to reach you:
- **Default Behavior**: When submitted, `js/main.js` validates the name, email, and message, and triggers the user's default email client (`mailto:gameof8ballpool01234@gmail.com`) with a prefilled subject and message body.
- **Customizing Destination Email**:
  Open `js/main.js` and edit line 146:
  ```javascript
  const mailtoUrl = `mailto:YOUR_EMAIL@gmail.com?subject=${subject}&body=${body}`;
  ```
- **Optional Form Backend (e.g. Formspree)**:
  If you prefer receiving submissions silently to your inbox without opening the user's mail client, replace the form action in `index.html`:
  ```html
  <form class="contact-form" action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
  ```

## 👤 Personalizing Profile Images & Logos

## 🌐 Deploying to GitHub Pages

1. **Commit and Push Changes**:
   ```bash
   git add .
   git commit -m "Update portfolio projects and articles"
   git push origin main
   ```

2. **GitHub Pages Configuration**:
   - In your GitHub repository, open **Settings** → **Pages**.
   - Under **Build and deployment** → **Branch**, choose **`main`** and **`/ (root)`**.
   - Click **Save**.
   - Your site will be live at `https://<your-username>.github.io/<repository-name>/`.
